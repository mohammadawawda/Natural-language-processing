# Natural Language Processing

Natural language processing projects in Python.

* [language_models](language_models) unigram and bigram language models on Wikitext
* [text_classification](text_classification) text classification with MLPs and a transformer
* [pos_tagging](pos_tagging) POS tagging with an HMM and the Viterbi algorithm
* [sentiment_analysis](sentiment_analysis) sentiment analysis with log linear models, an LSTM and a transformer
* [information_extraction](information_extraction) extracting triplets from Wikipedia with POS tags, dependency trees and an LLM

To install everything run `pip install -r requirements.txt`
